# Set-Piece Strategy Catalog — Framework Reference

## Core Concepts

Set-pieces (corners, free kicks, throw-ins) are rehearsed attacking and defensive routines. While they account for ~25-30% of goals in elite football, they are often undertrained relative to open play.

### Set-Piece Success Factors

1. **Delivery Quality:** Accuracy, trajectory, and pace of the ball
2. **Movement Patterns:** Coordinated runs to create space
3. **Timing:** Synchronization between delivery and runs
4. **Deception:** Disguising the intended routine
5. **Individual Quality:** Aerial ability, finishing, timing

## Corner Kick Strategies

### Attacking Corners

#### In-Swinging Corner (Right-Footed, Left Side)

**Setup:**
```
              Goal Line
     +---------------------+
     |                     |
GK   |  □    ■    □       |
     |  FB   CB   FB      |
     +---------------------+
        ^
      Taker
```

**Personnel:**
- **Near Post (□):** Strong header, attacks front post (5-7m from goal line)
- **Middle (■):** #9 or target man, attacks penalty spot (8-10m)
- **Far Post (□):** Secondary header, attacks back post (11-13m)
- **Edge of Box (●):** 2 players for second balls/clearances
- **Taker:** In-swinging delivery, near-post focus

**Delivery Zones:**
1. **Zone A (Near Post):** 40% of deliveries
   - Low, driven trajectory
   - Attacker makes 5-7m run from 6m out
   - Goal: Glanced header or volley

2. **Zone B (Middle):** 35% of deliveries
   - Medium trajectory, hanging
   - Attacker makes 8-10m run from edge of box
   - Goal: Power header or knock-down

3. **Zone C (Far Post):** 20% of deliveries
   - High, deep trajectory
   - Attacker makes 12-15m run from near post
   - Goal: Header back across goal or shot

4. **Short Corner:** 5% of deliveries
   - Pass to edge of box
   - Recipient dribbles or crosses
   - Goal: Create better angle or retain possession

**Movement Patterns:**
- **Near Post Attacker:** Wait, then sprint when ball is kicked
- **Middle Attacker:** Start wider, curve run to penalty spot
- **Far Post Attacker:** Start at near post, backpedal then sprint far post
- **Edge Players:** Hold position, attack loose balls

#### Out-Swinging Corner (Right-Footed, Right Side)

**Setup:** Same as in-swinging but taker on opposite side

**Delivery Zones:** Same distribution but different ball trajectory

**Additional Option:** Short corner to recipient who crosses with weaker foot (creates different angle)

#### Near-Post Flick-On

**Setup:**
- Near post attacker positioned 3-4m from goal line
- Middle attacker positioned 6-8m out
- Delivery: driven, low, to near post

**Movement:**
1. Near post attacker flicks ball toward middle
2. Middle attacker attacks flick
3. Far post attacker covers back post

**Success Factors:**
- Near post attacker's timing and directional control
- Middle attacker's anticipation of flick direction
- Delivery accuracy (near post, waist height)

#### Variable Routines

**Routine 1: "The Fake"**
- Taker acts like short corner
- 2 attackers edge toward corner
- At last moment, taker crosses long
- Attacker at near post has checked run, then attacks zone

**Routine 2: "The Double"**
- Taker plays short to edge player
- Edge player dribbles infield 2-3m
- Second player makes overlapping run
- Edge player crosses to overlapping player or into box

**Routine 3: "The Screen"**
- 3 attackers stand in wall in front of goalkeeper
- Taker crosses high
- Screeners block goalkeeper's view
- Other attackers attack space behind screen

### Defending Corners

#### Zonal Marking System

**Setup:**
```
              Goal Line
     +---------------------+
     |  □   □   ■   □   □ |
GK   |  (Zonal Markers)    |
     |                     |
     +---------------------+
        ^
      Taker
```

**Zonal Positions:**
- **Near Post (□):** 5-7m from goal, front post zone
- **Middle Front (□):** 8-10m from goal, penalty spot
- **Middle Back (■):** 10-12m from goal, behind penalty spot
- **Far Post (□):** 12-14m from goal, back post zone
- **Edge (□):** Edge of penalty area, for clearances

**Responsibilities:**
- Each marker owns their zone
- Attack ball when it enters zone
- Don't follow runners, protect space
- Goalkeeper claims crosses in their zone

**Man-Marking Mix:**
- Mark dangerous runners (1-2 opponents) man-to-man
- Rest of team defends zonally
- Mix prevents opponents from exploiting either system purely

#### Man-Marking System

**Setup:**
- Each defender marks a specific attacker
- Goalkeeper handles entire box
- Defenders stay tight to assigned attacker

**Responsibilities:**
- Touch attacker at all times
- Beat attacker to the ball
- Don't get drawn to other areas
- Goalkeeper communicates claims

**Counter:** Opponents can block runs, create space

#### Defensive Line Setup

**Line Distance:** 6-8m from goal line
- Close enough to attack balls
- Far enough to see delivery trajectory

**Number in Box:** 6-7 players
- 4-5 in zonal positions
- 1-2 man-marking dangerous opponents
- 2-3 players outside box for clearances

## Free Kick Strategies

### Attacking Free Kicks

#### Direct Free Kick (Shooting Range: <25m)

**Setup:**
```
              Goal
     +---------------------+
     |    Wall    |        |
     |  ● ● ● ●   |        |
GK   |     ●      |        |
     |             |        |
     +---------------------+
        ^
      Taker
```

**Delivery Options:**
1. **Direct Shot (60%):**
   - Over/around wall
   - Target top corner (farthest from goalkeeper)
   - Curve with inside of foot or power with instep

2. **Cross (30%):**
   - Driven low or lofted high
   - Target near post or far post runs
   - Similar movement patterns to corners

3. **Pass to Retain Possession (10%):**
   - Short pass to nearby player
   - Build from wide area
   - Patient attack

**Wall Setup:**
- Number of players: Distance (m) / 3 (e.g., 20m = 6-7 players)
- Jumping players: Every other player jumps to block
- Goalkeeper: Post farthest from shooter

#### Indirect Free Kick (Crossing Range: 25-35m)

**Delivery Options:**
1. **Cross into Box (70%):**
   - Driven low or lofted high
   - Target zones similar to corners
   - Movement patterns from set-piece routines

2. **Short Passing Combination (20%):**
   - Pass to nearby player
   - Overlap run
   - Cross from better angle

3. **Direct Shot (10%):**
   - Surprise element
   - Long-range specialist

### Defending Free Kicks

#### Wall Organization

**Distance from Ball:**
- Regulation: 9.15m (10 yards)
- Practical: 9-10m (give referee time to set)

**Number of Players:**
- Distance (m) / 3, rounded up
- 20m = 7 players
- 25m = 8-9 players

**Wall Setup:**
- End player covers near post angle
- Middle players cover goal
- Farthest player covers far post angle
- Goalkeeper covers opposite post

**Positioning:**
- End player: Behind wall, ready to step
- Jumping players: Every other player
- Non-jumping: Cover ground balls

**Communication:**
- Designate wall organizer (usually CB)
- Organizer signals number of players
- Goalkeeper signals which post to cover

## Throw-In Strategies

### Long Throw-In

**Setup:**
- Thrower 30-35m from goal line
- 3-4 attackers in penalty area
- 1-2 attackers at edge of box

**Delivery Zones:**
1. **Near Post:** 40% of throws
   - Low, flat trajectory
   - Attacker flicks toward goal or other attackers

2. **Middle:** 35% of throws
   - Higher trajectory
   - Attacker attacks ball at highest point

3. **Far Post:** 20% of throws
   - Highest, longest trajectory
   - Attacker runs from near post to far post

4. **Short:** 5% of throws
   - Retain possession
   - Build attack

**Movement Patterns:**
- Similar to corner kick routines
- Attacker screening (blocking defender) allowed
- Thrower can move along touchline before throwing

### Short Throw-In (Possession Retention)

**Setup:**
- Thrower 5-10m from goal line
- 3-4 players in support triangle
- Objective: Retain possession, not score directly

**Movement:**
- Create 2v1 overload near touchline
- Pass back to thrower if marked tightly
- Combination play to progress

## Set-Piece Training Sessions

### Corner Kick Session

**Part 1: Delivery Practice (15 min)**
- 2 takers, 10 balls each
- Alternate: 5 near post, 5 middle, 5 far post
- Coaching points: Consistency, trajectory, accuracy

**Part 2: Attacking Routines (20 min)**
- Full team (GK + 10 outfield)
- 3 routines, 5 reps each
- Markers: bibs or poles
- Coaching points: Timing, movement, coordination

**Part 3: Defensive Organization (20 min)**
- Full team defense vs coach-delivered corners
- 5 reps zonal, 5 reps man-marking
- Coaching points: Positioning, communication, clearing

### Free Kick Session

**Part 1: Wall Organization (10 min)**
- Coach blows whistle, players organize wall
- Distance, number of players, positioning
- Coaching points: Speed, communication, positioning

**Part 2: Defensive Setup (15 min)**
- Opponents set up attacking free kick
- Coach delivers ball
- Players defend, clear, counter
- Coaching points: Focus, clearing, transition

**Part 3: Attacking Routines (20 min)**
- 3 routines: direct shot, cross, combination
- 5 reps each
- Coaching points: Delivery, movement, timing

### Set-Piece Competition

**Game:** 6v6 + goalkeepers
- Normal small-sided game
- Set-piece situations every 2 minutes
- Corners, free kicks, throw-ins
- Points: 3 for goal from set-piece, 1 for open-play goal
- Winning team gets choice of next drill

## Set-Piece Analysis

### Tracking Set-Piece Performance

**Attacking Metrics:**
- Shots per set-piece
- Goals per set-piece
- xG per set-piece
- Conversion rate (goals / shots)

**Defensive Metrics:**
- Shots conceded per set-piece
- xG conceded per set-piece
- Clearances per set-piece
- Possession won back

**Analysis Categories:**
- Corners (In-swinging, Out-swinging, Short)
- Free Kicks (Direct, Indirect)
- Throw-ins (Long, Short)
- Goal Kicks (Short, Long)

### Optimization Checklist

**Pre-Match:**
- [ ] Identify opponent's set-piece strengths/weaknesses
- [ ] Select routines based on opponent's defensive system
- [ ] Assign personnel to specific roles
- [ ] Rehearse routines in warm-up

**During Match:**
- [ ] Track set-piece opportunities
- [ ] Adjust routines based on opponent's positioning
- [ ] Communicate changes to players
- [ ] Maintain concentration on all set-pieces

**Post-Match:**
- [ ] Analyze set-piece xG
- [ ] Review video of set-pieces
- [ ] Identify successful routines to repeat
- [ ] Identify unsuccessful routines to adjust
